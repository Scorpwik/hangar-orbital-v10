## Preguntas para el cliente (2 de diciembre)

1. **¿El contador puede mostrar «4 de 3»?** Spec 02, decisión 3 / `[SUPUESTO]`: si llegan datos antiguos, el número real supera el máximo y todas las marcas se ocupan. Falta confirmarlo antes de cerrar E1.
2. **¿Qué se muestra si falla guardar el combustible?** Spec 06, Pendiente 3 / `[SUPUESTO]`: hoy aparece «No se pudo corregir el combustible.» y no hay aviso de éxito, porque la barra ya muestra el cambio.
3. **¿«Aurora» y «aurora» son la misma nave?** Spec 01, Pendiente 2: nombres que solo difieren en mayúsculas.
4. **¿Qué día es «hoy» al completar una misión?** Spec 07, Pendientes: fecha local de la app frente a `current_date` (UTC) en la base.
5. **¿Se puede completar una misión de una nave en dique seco?** Spec 07, Pendientes: hasta HU-2.3 / R6, la app lo permite.
6. **¿Una misión cancelada o fallida existe?** PRD `[SUPUESTO]` y backlog de HU-2.3: el modelo actual solo tiene `pendiente` y `completada`.
